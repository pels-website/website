# Требования и техническая спецификация веб-сайта

## 1. Ключевые требования к интерфейсу и UX

### Солидный и презентабельный вид (Executive Aesthetic)
- **Визуальная идентичность:** Использование премиальной цветовой палитры (темно-синий/бордовый с кремовым фоном).
- **Сдержанный стиль:** Отсутствие кричащих баннеров, анимаций и дешёвых маркетинговых элементов.
- **Имидж:** Акцент на многолетний опыт (45+ лет практики), авторитет и надежность.

### Адаптивность для людей с дислексией (Dyslexia-Friendly)
- **Типографика:** Четкие шрифты с хорошей межбуквенной и межстрочной интервалом (line-height).
- **Контрастность:** Соблюдение стандартов WCAG AA/AAA по контрастности текста относительно фона.
- **Низкий визуальный шум:** Отказ от фоновых фоновых фоновых рисунков, водяных знаков и слоистых элементов, вызывающих зрительную усталость.
- **Структура:** Короткие абзацы, четкие списки, выделение ключевых мыслей полужирным шрифтом.

### Быстрый доступ к контактам (Quick Access Contact)
- **Первичная консультация:** Заметный блок с информацией о бесплатном 15-минутном вводном звонке.
- **Разнообразие каналов:** Быстрый выбор между личной встречей в Вильнюсе и видеосвязью (MS Teams, Zoom, WhatsApp, Viber, телефон).
- **Доступность в 1 клик:** Прямые интерактивные ссылки `tel:` и `mailto:` без необходимости переходить на отдельные страницы.

---

## 2. Технические характеристики и функционал

### Мультиязычность (Language Support)
- **Языки:** Поддержка литовского (`lt`), английского (`en`) и русского (`ru`) языков.
- **Архитектура:** Использование JSON-файлов перевода (`lt.json`, `en.json`, `ru.json`) с управлением через URL-параметр `?lang=`.
- **Изоляция:** Единый HTML-файл без дублирования страниц для каждого языка.

### Адаптивный дизайн (Responsive Design)
- **Mobile-First:** Полная адаптивность под любые разрешения экранов (смартфоны, планшеты, десктопы).
- **Безопасные зоны:** Корректное отображение контента и кнопок в пределах видимости без горизонтального скролла.

### Превью в мессенджерах и соцсетях (Social Previews & Edge Injection)
- **Open Graph / Twitter Cards:** Настройка метатегов `og:title`, `og:description` и `og:image`.
- **Динамическая подстановка:** Использование Cloudflare Pages Functions (`HTMLRewriter`) для отдачи превью на языке запроса (`?lang=`) до отрисовки клиентом.
- **Оптимизация изображений:** Единая SVG/PNG карточка (1200×630px) с безопасной центральной зоной (630×630px).

### Поисковая оптимизация (SEO & Schema Markup)
- **Структурированные данные:** Внедрение микроразметки JSON-LD (`schema.org/LegalService`) для Google Knowledge Graph.
- **Индексация:** Настройка метатегов `robots` и директивы `max-image-preview:large` для отображения крупных фото в выдаче Google.
- **Мультиязычное SEO:** Поддержка тегов `hreflang` для связи языковых версий.

### Фавиконки и иконки (Favicons & Assets)
- **Форматы:** Набор иконок для всех устройств (`favicon.ico`, `favicon-32x32.png`, `apple-touch-icon.png`).
- **Манифест:** Файл `site.webmanifest` для корректного отображения при сохранении на рабочий стол смартфона.

### Доступность для ИИ-сканеров (AI & LLM Readability)
- **Файл `llms.txt`:** Наличие текстового файла в корне сайта (`https://yourdomain.lt/llms.txt`) с краткой структурированной информацией о практике для ИИ-ассистентов и поисковых моделей.

### Архитектура и скорость (Performance & Cloudflare)
- **Статический стек:** Чистый HTML, CSS и JS без тяжелых фреймворков.
- **Хостинг:** Бесплатное глобальное CDN-размещение на Cloudflare Pages с мгновенным откликом (Core Web Vitals 95+).
